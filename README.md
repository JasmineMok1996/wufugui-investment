## 🛠 配套工具

`scripts/grid_calculator.py` — 输入股票代码，自动计算周线布林带位置百分位与当前档位：

```bash
python grid_calculator.py sh600036 week 30
# 现价 39.58 | 位置 87.3% | 周中偏上 | 持有可降本，未持有不追
```

> ⚠️ 脚本依赖 `westock-data` 数据接口（`WESTOCK`/`NODE` 路径在文件头配置，请按本机实际修改）。
