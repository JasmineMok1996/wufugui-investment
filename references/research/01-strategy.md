# 01-策略总纲与著作

来源：小红书博主「还是叫吴富贵吧」18+篇笔记OCR + 雪球/微博/知乎第三方整理
信息可信度：笔记OCR一手 > 第三方转述二手

## 一句话策略

「像买收租的房子一样买股票」：只买央国企高分红龙头，等股价跌便宜了买，每年收分红（房租），分红再投（复利滚雪球），涨到股息率太低就卖，换下一只便宜的。

## 策略全貌（三层嵌套体系）

1. **股息率选股**（买什么）：央国企龙头 + 千亿市值 + 连续分红10年 + 股息率达标
2. **股息率择时**（何时买/卖）：股息率6~7%买、3~4%抛
3. **网格执行**（怎么买/卖）：周线布林带分档，周中偏下牵手、周上嗖掉

## α（选股）标准

| 维度 | 标准 |
|------|------|
| 企业性质 | 央企/国企，优先垄断、特许经营、永续经营（水电气煤电信银行高速白酒） |
| 行业地位 | 行业龙头 |
| 市值 | 千亿以上（几千亿、万亿更佳） |
| 分红历史 | 连续正常分红10年以上，排除突击分红 |
| 股息率 | 买入时4%~6%，下限约4.5%（行业略有差异） |

## β（择时）标准

四个条件共振，缺一不可：
1. 股价从高位连续下跌3~5年，接近腰斩
2. 月线、季线处于历史低位
3. BOLL日/周/月线下轨共振（月下吸）或日线周线下轨+月线回踩中轨（龙回头）；月线MACD入坑后起来
4. 股息率被动抬升到4.5%以上

## 卖出规则

- 股价上涨 → 股息率被动下降 → 跌到3%~3.5%（部分行业2%~3%）抛出
- 口语版：「股息6~7开始买，股息3~4抛」
- 终极形态：股价创月线新高、股息率3%左右时收本金，利润当0成本股权长期留

## 策略升级（关键转折）

- 早期：「资源不对称」集中重仓2~3只，必须买对
- 现在：**分散20~30只各行业龙头 + 少犯错**——把"必须对"换成"少犯错"
- 触发事件：朋友重仓万科（地产龙头）"陆家嘴一套房进去，变成彭浦新村一套房"
- 他自己也因集中持股"心魔"失眠过
- 论证：巴菲特早年持仓也不是传说中的只买几只

## 终极目标

退休后不工作，靠分散持股的分红现金流生活（"看得到的回报"）——现金流稳定且风险更低。
