# 03-网格交易方法论

来源：笔记OCR + 多轮问答拆解（一手 + 提炼）
信息可信度：一手规则 + 计算推导

## 网格本质

不预测涨跌，只赚"来回震荡"的钱。像菜贩子：跌到便宜价进货，涨到贵价卖出，来回晃就反复赚差价。

## 布林带（BOLL）基础

- 中轨 = 最近20周收盘价平均值
- 波动幅度 = 20周价格标准差（平时晃动幅度）
- 上轨 = 中轨 + 2倍波动；下轨 = 中轨 − 2倍波动
- 股价约95%时间在上下轨之间晃
- 波动大的股票袋子宽，波动小的袋子窄

## 五档划分（位置百分位法）

位置 = (现价 − 下轨) ÷ (上轨 − 下轨) × 100%

| 位置 | 档位 | 动作 |
|------|------|------|
| 0%~10% | 周下 | 极致买点，重仓买 |
| 10%~40% | 周中偏下 | 牵手（买） |
| 40%~60% | 周中 | 观望 |
| 60%~90% | 周中偏上 | 开始降本（卖一点） |
| ≥90% | 周上 | 卖出 |

## 网格切格

- 网格区间 = 下轨到上轨
- 等分法（推荐）：切5格，每格 = (上轨−下轨) ÷ 5
- 招行示例：下轨35.09、上轨40.23，区间5.14元，每格≈1元

## 资金分份（永远留子弹）

- 总预算分5份，每格动1份，永不满仓
- 买：越跌越买，最多买3份（60%），留40%现金（含跌破下轨的子弹）
- 卖：越涨越卖，逐步吐回
- 单只 ≤ 5%~10%，行业 ≤ 30%~40%

## 台阶理论（动态机制）

- "台阶"不是切小格，是价格整体上移、中轨跟着上移
- 周中偏下是"会动的相对位置"：价格上台阶后，原来的中间自动降成偏下（新买点）
- 铁律：价格上台阶冲高时别追（"不体面的时间"），等回踩到新"周中偏下"再牵手

## 线什么时候动、人什么时候动

- 周线布林带每周收盘才动一次，一周内基本不变
- 锚点=中轨（20周均价），自动跟随价格，不用设不用重画
- 人只在价格走到"周中偏下"（买）或"周上"（卖）时才动手

## 两种买点模式

| | 月下吸（跌透） | 龙回头（回踩） |
|---|---|---|
| 信号 | 日+周+月三线BOLL都触下轨 | 日+周下轨 + 月线回踩中轨 |
| 含义 | 跌到极致超卖 | 第一波涨完回踩不破再启动 |
| 前提 | 月线MACD从坑里爬起来 + 股息率≥4.5% | 同左 |

## 网格三个坑

1. 单边下跌越买越套 → 只对央国企高分红龙头用网格（套住还有分红）
2. 单边上涨卖飞 → 上去了坚决分手，不贪
3. 必须留子弹 → 永不满仓、留20%现金

## 网格实战示例（1万元预算、招行）

| 价格 | 动作 | 金额 |
|------|------|------|
| 37~38（周中偏下） | 买第1份 | 2000 |
| 36~37 | 买第2份 | 2000 |
| 35~36（周下） | 买第3份 | 2000 |
| 39~40（周中偏上） | 卖第1份 | 2000 |
| >40（周上） | 卖第2份 | 2000 |
| <35（下轨以下） | 留子弹 | 4000 |
